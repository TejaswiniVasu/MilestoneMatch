# MilestoneMatch recording plan

Target duration: **2 minutes 50 seconds**, leaving margin under three minutes.
Use the hosted app: https://milestone-match.onrender.com/.

## Prepare before recording

- Open the app early so the free Render service wakes. Use a fresh review in the
  same tab throughout checkout. Do not deploy/restart during the take.
- Sign in to the US personal PayPal **Sandbox** buyer off camera. Close developer
  dashboards, environment settings, email and unrelated tabs; hide notifications.
- Rehearse once. Confirm Channel3 and the background flow return successfully.
- Open the actual Render workflow run page in another tab if showing run history.
  Keep API keys and environment values off screen.
- A real capture already works, but each recording should show a fresh actual
  capture. Never substitute a mocked receipt. Editing out login/waiting is fine;
  label a cut as “waiting shortened” instead of pretending instant execution.
- Use original narration. Do not claim the AI inspected the underlying files,
  verified completion, autonomously paid, or measured real customer savings.

| --- | --- | --- |

| 0:45–1:20 | Open real Sandbox checkout; show USD 240, approve and return. Shorten waiting if necessary. | “The PayPal Server SDK creates an order for exactly my selected milestones. PayPal approves the Sandbox payment, and the server checks the capture amount and review identity.” |

| 1:32–1:48 | Open analytics; point to selected versus captured and filter a status. | “AG Studio separates proposals from captured payments, with linked filters, a chart and a decision ledger.” |

If the narrated take exceeds three minutes, shorten transitions and waiting,
not the proof of the actual PayPal capture. Do not imply the demo covers Studio
Agent Framework or autonomous commerce; those are not implemented.

## After recording

- Watch the full export: legible amounts, audible narration, no credentials,
  correct Sandbox labels and a runtime under three minutes.
- Upload publicly to YouTube and test access while signed out. Keep a local copy.
- Add the video, clean hosted URL and public source branch to Devpost. Use the public
  repository at https://github.com/TejaswiniVasu/MilestoneMatch with its complete
  default branch.
- Complete eligibility/originality and third-party licensing fields truthfully.
  The entrant must review and submit the final form.

## Small user-feedback session

Ask two or three willing freelancers/clients to try the synthetic sample. Do not
message anyone automatically. Ask which milestones they would approve, whether
the quoted evidence helps, and what they would still inspect before paying.
Record the actual number of testers, observations and any confusion. Use these
findings in the submission only after collecting them; do not invent impact data.
